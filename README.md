# your-turn-games

Author games for the **«Твой ход!»** platform: a Python reducer + a static client,
developed and tested fully offline with the stdlib dev harness.

## Quickstart

```bash
git clone <this repo> && cd your-turn-games
python -m harness --game games/tic-tac-toe
# open the printed URLs (one per seat) in two browser tabs
```

See [CONTRACT.md](CONTRACT.md) for the game contract and [SKILL.md](SKILL.md) for
the authoring guide.
